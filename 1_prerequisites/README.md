# Prerequisites: do these 24 hours before the workshop

**Total time:** about 90 minutes. **Cost:** $0.

Do the guides in this order. Each ends with a check, so you know it worked.

| # | Guide | Time | You finish with |
|---|---|---|---|
| 1 | `SETUP_GUIDE.md` | 30 to 45 min | VS Code, Python 3, and Copilot Free signed in. `check_setup.py` passes. |
| 2 | `ATLASSIAN_SETUP.md` | 20 min | A free Atlassian site (Jira project `BRT`, Confluence space `BRT`), connected to VS Code. |
| 3 | `PREREQUISITE_CREATE_CONFLUENCE_AND_JIRA.md` | 20 min | 3 Confluence pages with 4 screenshots, and 1 Jira epic with 3 tickets. You create them with two paste-in prompts. |

Other things in this folder:

| Item | What it is |
|---|---|
| `check_setup.py` | A script that tests your computer. Run it from the workshop folder: `python3 1_prerequisites/check_setup.py` (Windows: `python`). It changes nothing. |
| `atlassian_seed/content/` | The text for the pages and tickets you create (Markdown). |
| `atlassian_seed/screenshots/` | The 4 screenshots you add to the Confluence reference page. |

**Privacy rules**

- The workshop uses only a fictional company. Never paste real company content into a free AI tool.
- Use a **personal** email for GitHub and Atlassian, never a work account.

**Stuck?** Each guide has a troubleshooting table. If you cannot finish step 2 or 3, come anyway. You will watch the Atlassian parts, and you keep everything else.
