# STC India Annual Summit 2026 - AI Workshop

Skills, agents, hooks, plugins, and MCP for technical communicators

A hands-on workshop in VS Code with GitHub Copilot Free. One use case runs through every module: updating Brightside Co.'s "How to request time off" page, backed by a free Jira and Confluence site.

**Workshop page:** <https://adstalwar04.github.io/stc2026/>

## If you are attending

Do the prerequisites **at least 24 hours before** the session. They take about 90 minutes and cost nothing.

1. Open [`1_prerequisites/README.md`](1_prerequisites/README.md). It gives the order of the three guides.
2. Follow [`SETUP_GUIDE.md`](1_prerequisites/SETUP_GUIDE.md): VS Code, Python 3, and GitHub Copilot Free.
3. Follow [`ATLASSIAN_SETUP.md`](1_prerequisites/ATLASSIAN_SETUP.md): a free Atlassian site, connected to VS Code.
4. Follow [`PREREQUISITE_CREATE_CONFLUENCE_AND_JIRA.md`](1_prerequisites/PREREQUISITE_CREATE_CONFLUENCE_AND_JIRA.md): create the Confluence pages and Jira tickets with two paste-in prompts.

The organizer shares the materials you use during the session with registered attendees.

If you cannot finish steps 3 or 4, come anyway. You will watch those parts and keep everything else.

**Privacy:** the workshop uses only a fictional company. Never paste real company content into a free AI tool, and use personal accounts, not work accounts.
