# STC India Annual Summit 2026 - AI Workshop

Skills, agents, hooks, plugins, and MCP for technical communicators

A hands-on workshop in VS Code with GitHub Copilot Free. One use case runs through every module: updating Brightside Co.'s "How to request time off" page, backed by a free Jira and Confluence site. Choose the 2-hour express edition or the 3.5-hour full edition.

## The four folders

| Folder | For | Start with |
|---|---|---|
| `0_promo/` | Advertising the workshop | `workshop_promo.html`: a one-slide interactive page. Open it in a browser. |
| `1_prerequisites/` | Participants, **before** the session (about 90 minutes) | `README.md`, then `SETUP_GUIDE.md` |
| `2_participants/` | Participants, **during** the session | `PARTICIPANT_HANDOUT.md` |
| `3_facilitator/` | The facilitator only | `README.md` |

## What to send to whom

- **Participants:** `1_prerequisites/` and `2_participants/`. Do not send `3_facilitator/`: it holds the reveal for the trust challenge and the answer to the late-label twist.
- **Facilitator:** everything.
- **Website or marketing:** `0_promo/` and the text in `3_facilitator/SESSION_LISTING.md`.

## Quick path for the facilitator

1. Read `3_facilitator/README.md`.
2. Do the prerequisites yourself on a fresh free Atlassian site.
3. Rehearse `3_facilitator/WORKSHOP_2HR.md`.
4. Send the participant folders with a 24-hour deadline.
